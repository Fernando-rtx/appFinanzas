# Mis Finanzas

App Android para organizar gastos mensuales. Construida con Kotlin, Jetpack Compose, Material 3 y Room.

## Requisitos

- [Android Studio](https://developer.android.com/studio)
- JDK 17+

## Ejecutar localmente

1. Abrir Android Studio
2. Seleccionar **Open** y elegir el directorio del proyecto
3. Permitir que Android Studio sincronice las dependencias
4. Ejecutar en un emulador o dispositivo físico
